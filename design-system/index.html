Design system · French Learning for World

Every value below comes from tokens.css. Nothing on this page defines a colour, size, radius or duration of its own — that is the point of the page. Toggle the theme and the direction with the buttons above; both are part of the system, not an afterthought.

Fonts are self-hosted. Newsreader and Vazirmatn are served from our own origin, both OFL-1.1, both variable so one file covers every weight. Nothing is requested from a third party, the service worker can cache them, and unicode-range means a Latin page never downloads the Arabic subset.

Colour

Semantic names only. Neutrals carry a slight blue bias toward the accent — a pure grey beside a coloured accent reads as unconsidered. Every value is declared on bare :root first, then redefined twice for dark: once behind prefers-color-scheme for the majority whose system is set to auto, and once behind [data-theme="dark"] for an explicit choice. Omit either and one group gets one theme’s text on the other theme’s background, with no error.

Type

Two families. Newsreader carries French — a text serif with enough character to make a headword feel like a word rather than a data field, and proper accents at display size. Vazirmatn carries the interface and covers Latin, Persian and Arabic from one family, which is why the right-to-left languages need no separate stack. Modular scale; nothing is “18px because it looked right”.

French typography — implemented, not left to authors

A narrow no-break space (U+202F) before ; ! ?, a no-break space (U+00A0) before : and inside guillemets, a typographic apostrophe, and accents kept on capitals. One formatter applied at render, with unit tests.

Accessibility, measured

Contrast is computed against the real rendered background for every text element on this page, in both themes, by design-system/contrast-check.mjs. The result is a number, not a claim. Tab through this page: every control shows a 2 px focus ring with the same treatment everywhere, and nothing sets outline: none.
