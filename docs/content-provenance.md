# Content provenance

Every item of learning content in this project carries a recorded source and
licence. This is not bookkeeping — it is what lets anyone verify that the
whole content set is free to use, and what lets an attribution page generate
itself rather than be maintained by hand.

## The rule

**If you cannot state where an item came from and under what licence, it does
not ship.** Uncertain provenance means the item is left out, not guessed at.

## Excluded, without exception

- Text, dialogues, exercises or examples from commercial textbooks, workbooks
  or paid courses — including paraphrases of them.
- Curated vocabulary lists from published works. A *selection* of words is the
  compiler's own work even when none of their sentences are copied; in the EU
  it is additionally protected by the database right, independently of
  copyright.
- Content scraped from another learning app or platform.
- Audio from sample libraries without a licence record. "Probably CC0" is not
  a licence record.

Word lists for this project are derived from **frequency in open corpora**,
never from someone's curation. Frequency is a fact, and facts are free.

## Sources under consideration

| Source | Licence | Used for |
|---|---|---|
| [Lexique 3](http://www.lexique.org/) | CC BY-SA 4.0 | Headword selection by frequency; lemma and part-of-speech data |
| [Tatoeba](https://tatoeba.org/) | CC BY 2.0 FR (some CC0) | Example sentences with translations |
| [Wiktionary](https://fr.wiktionary.org/) | CC BY-SA 3.0 | Definitions, gender, conjugation |
| [Wikidata](https://www.wikidata.org/) | CC0 | Lexeme data |
| [Lingua Libre](https://lingualibre.org/) | CC BY-SA | Native-speaker word audio |
| [Mozilla Common Voice](https://commonvoice.mozilla.org/) | CC0 | Native-speaker sentence audio |
| [OPUS](https://opus.nlpl.eu/) | varies per corpus | Parallel FR–EN text |
| [Universal Dependencies (French)](https://universaldependencies.org/) | CC BY-SA | Annotated syntax |
| Wikisource / Project Gutenberg | public domain | Reading passages (C1–C2 register only) |

Each corpus is verified individually before use — a licence in this table is
a starting point, not a clearance.

## Share-alike

Several sources above carry **share-alike** terms: work derived from them must
be released under a compatible licence. This is acceptable for a free
platform, but it constrains the content set permanently, so the mix is decided
deliberately before content ships rather than discovered afterwards.

Code (MIT) and content are licensed separately.

## CEFR levels

There is no freely licensed official CEFR vocabulary list. Levels assigned
here are **a judgement applied consistently across the whole set, based on
corpus frequency and how early a learner meets a word — not a certification**,
and the project does not claim official alignment with any examination.

## Recorded per item

Content rows carry their own `provenance` and `sourceRef`, so the question
"may we publish this?" is a query, not an investigation.
